# Casos de uso — FLSalud

- **Admin:** gestionar usuarios/médicos/recepcionistas, horarios y reportes.
- **Recepcionista:** buscar/registrar pacientes, asignar y reprogramar citas, consultar agenda y disponibilidad.
- **Médico:** consultar agenda, registrar datos del paciente, crear/editar consulta, revisar historial y emitir constancias.
- **Paciente:** consultar citas próximas/pasadas, perfil y constancias.
- **Sistema:** autenticación, permisos y base para notificaciones por correo.
